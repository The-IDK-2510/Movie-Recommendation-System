# Movie Recommendation System

This is a group project for a Machine Learning based Movie Recommendation System.

## Dataset

The dataset contains information about movies such as:

- Movie title
- Genres
- Overview
- Release date
- Popularity
- Rating
- Vote count
- Budget
- Revenue

## Dataset File

The movie database is stored in:

`movies_metadata.csv.gz`

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook
- Flask
- Streamlit

## My contribution
Create a Machine Learning model for the recommendation system using NLP techniques such as TF-IDF vectorization and Cosine Similarity from the clean and integrated data. 

The objective of this project is to recommend movies to users based on
similarity between movies and their characteristics.
